Connect Spotify

Use PKCE login with your Spotify Client ID, or paste an existing access token.

How To Connect

  1. Go to the Spotify Developer Dashboard and create an app.
  2. Copy the app Client ID.
  3. Add this redirect URI in the app settings: http://127.0.0.1:8000/callback
  4. Return here, paste the Client ID, and press CONNECT.
  5. Approve the browser permission prompt. Focus will connect when Spotify redirects back.

If OAuth is blocked, paste a valid Spotify access token in the fallback field.
